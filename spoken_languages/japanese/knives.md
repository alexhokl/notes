# 刃物

| Name | Description |
| --- | --- |
| 本出刃(ほんでば) | 厚みと重さが特徴の片刃の包丁。魚のぶつ切りや捌き、鶏肉などを切るときに使います。家庭用は15cm〜、プロ用は21cm〜が一般的です。 |
| 相出刃(あいでば) | 本出刃より薄い片刃の包丁。魚のぶつ切りや捌き、鶏肉などを切るときに使います。家庭用は15cm〜、プロ用は21cm〜が一般的です。 |
| 菜切(なきり) | 両刃の野菜用の包丁。刃が水平で幅が広いので、白菜などかさのある野菜を切るのに便利です。家庭用は15cm〜。型は関西型と関東型があります。 |
| 柳刃(やなぎば)と蛸引(たこびき) | 柳刃包丁は刺身を造るときの包丁。魚の切り口を鮮やかに、美しく仕上げます。刃の長さを利用してスーッと引くように使います。21cm以上必要です。蛸引包丁は柳刃包丁の関東型。刃先が四角く、刃が直線的になっています。 |
| 薄刃(うすば) | 片刃の野菜専用の包丁。刃が鋭角のため野菜が切りやすいよう工夫されています。関西は鎌型で、関東は角型です。柳刃包丁は刺身を造るときの包丁に、美しく仕上げます。刃の長さを利用してスーッと引くように使います。21cm以上必要です。 |
| 中華(ちゅうか) | 起源は中国ですが、日本独自の形に変化しています。種類は3種類。薄手は肉や野菜、中厚は万能、厚手は骨の叩き切り用です。18cm～。 |
| 牛刀 | 肉以外に野菜、小魚の捌きなどにも使える両刃の万能包丁。家庭用18～21cm、プロ用24～30cm。 |
| ペティナイフ | 果物や野菜の皮むき、細工切りなどに使われる包丁。牛刀の小型サイズ。11～18cm のものをペティナイフと呼びます。 |
| 鮪切(まぐろきり) | 大型の魚を解体する包丁。切り落とした部分が傷つかないよう非常に大きく作られています。大きいものは1.5mあります。 |
| 鰯切(かつをきり) | 骨を切るためのもの、血を抜くためのものなど用途によって、それぞれ形が違います。 |
| 鮭切(さけきり) | 鮭などの大きな魚を皮・骨ごと切り身にするときに使います。出刃包丁より薄く作られています。 |
| 鰻切(うなぎきり) | 鰻は骨が多くて硬いので、包丁の重さを使って小骨が切れるようにできています。刃は薄く作られています。 |
| 鯨切(くじらきり) | 鯨の解体用。薙刀のような形で鯨の皮を切り裂きます。 |
| 鰒引(ふぐびき) | 鰻の切り身を薄く切るため、柳刃包丁より峰の厚みは薄く、身幅は狭くなっています。24cm〜。 |
| 鰻裂(うなぎさき) | 関西は腹開き、関東は背開きと地域により裂き方が異なるため、形は違います。関西は切っ先が切り出し型で柄尻まで地鉄。関東は関西と同じく切り出し型で、柄付き。名古屋は細長く長方形。京都市鎗の形。九州は出刃包丁のような形です。 |
| 麵切(めんきり) | 関西はうどん切り包丁、関東はそば切り包丁と呼びます。１回切り落とすと１本の麺が均等に切れるように刃渡りの長い独特の形です。24cm～。 |
