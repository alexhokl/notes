# Adjectives

## い-adjectives

- fun facts
  * it is the original native adjective class; な-adjectives grew later,
    largely to absorb kango and loanwords
  * almost always wago rather than kango or other origin
- types
  * ending with しい
    + used for more personal, emotive or "internal" characteristics
  * ending with い
    + generally describe physical characteristics
- irregular conjugation
  * いい - good
    + conjugates from よい (e.g. よくない, よかった)
  * かっこいい - cool; stylish
    + conjugates from かっこよい (e.g. かっこよくない, かっこよかった)
- used at the end of a sentence
  * examples
    + お母さんの料理はおいしい。
- used before a noun
  * examples
    + 古い車
- convert to an adverb
  * replace い with く
  * examples
    + 彼らは`楽しく`暮らしていました。 - They lived happily.
    + 新しく
  * exception
    + いい -> よく
    + かっこいい -> かっこよく

### そう

- it can be added to adjectives to mark them as speculative
  * similar to "looks"
  * it is not used when the quality is plainly visible
    + e.g. きれいそう and 赤そう are unnatural; say きれいだ or きれいに見える
      instead
- formatting
  * affirmative
    + replace い with そう
    + examples
      + 美味しそう - looks delicious
      + 美味しそうだ。 - It looks delicious. (stronger)
      + 美味しそうです。 - It looks delicious. (polite)
      + あのアパート、狭そう。 - That apartment looks small.
      + あの人、優しそう。 - That person looks kind.
      + エアコン持ってないの？ええ〜、部屋暑そう。 - You don't have an air
        conditioner? Wow, your room must get hot.
    + exceptions
      + いい -> よさそう
      + ない -> なさそう
      + 少ない -> 少なそう (not 少なさそう; only ない and よい/いい insert
        さ)
      + かわいい -> かわいそう means "pitiful; poor thing" rather than "looks
        cute"; use かわいらしい or かわいく見える instead
  * negative
    + replace the final い of the negative form with さそう (くない ->
      くなさそう)
    + examples
      + 美味しくなさそう - does not look delicious
      + 美味しそうじゃない。 - It does not look delicious. (a softer version)
- used like a な-adjective
  * examples
    + 美味しそうなケーキだね。 - That looks like a delicious cake.
- used like an adverb
  * examples
    + おいしそうに食べています。 - They are eating it with relish (it looks
      like they find it delicious).
- tricky case
  * instead of replacing い with そう, appending そう to the plain form of the
    い-adjective (keeping the い) means you have heard something (hearsay)
  * it must be followed by だ or です
  * it cannot be used before a noun or as an adverb; そうな and そうに only
    carry the "looks" meaning
  * the hearsay そうだ itself is not negated or put in the past; negate or
    put the adjective in the past before appending そう instead
  * examples
    + あのケーキ、美味しいそうです。 - I heard that cake is delicious.
    + あのケーキ、美味しくないそうです。 - I heard that cake is not
      delicious.

## な-adjectives

- it can be used to describe a noun
- some of them can also function as a noun
  * examples
    + 自由 (じゆう) - freedom; free
    + 健康 (けんこう) - health; healthy
  * others, such as 静か (しずか), cannot
- it can be converted to an adverb
  * by adding に
  * examples
    + 私は静かにドアを閉めた。
    + 桜が綺麗に咲いていた。 - The cherry blossoms were blooming beautifully.
    + 部屋が綺麗に片付いていた。 - The room was beautifully tidy.

### そう

- see explanation in [そう](#%E3%81%9D%E3%81%86)
- formatting
  * affirmative
    + append そう to the adjective stem (without な)
    + examples
      + 便利そう - looks convenient
  * negative
    + append じゃなさそう (or the more formal ではなさそう) to the adjective
    + examples
      + 便利じゃなさそう - does not look convenient
- tricky case
  * appending だそう to the adjective means you have heard something
  * examples
    + 便利だそうです。 - I heard it is convenient.
    + 便利じゃないそうです。 - I heard it is not convenient.
